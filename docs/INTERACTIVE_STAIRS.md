# 原生楼梯动画与交互

本次增量在原生 SwiftUI “我的楼梯”中替换静态楼梯，保留 HealthKit、上海日界线、昵称、缓存提示与后端同步规则。仅修改已有源文件与已关联的 XCTest 文件，不新增依赖或更改工程 target。

## 行为

- 同一天成功读取的步数跨层后，人物按层登梯，弹簧位移动画和步态变化随进度播放。最多播放最近8层，约2.6秒，避免数千层补算产生长动画；图中明确提示“展示最近N层”。楼层标题和下方步数始终来自真实快照。
- 首次进入/日期切换直接定位，步数向下修正直接更新。旧日、离线缓存、切后台或减少动态效果不播放新增进度反馈。动画任务随日期、快照、缓存状态、系统动态效果偏好、前后台及回放请求变化取消并重建，不创建重复定时循环。
- 点选任一可见楼层显示已走过/当前位置/距离目标还差多少步；左右滑动或方向按钮浏览附近楼层，使用“回到我”重新定位。
- 下一层进度条展示真实步数余量。回放按钮只播放最近最多4层已完成进度，明确标注“不计入步数”，不会修改模型、访问 HealthKit 写入或触发联网请求。缓存和减少动态效果状态下禁用回放。
- 新增真实进度完成时提供系统成功触感；点选/浏览提供选择反馈。回放不触发到达成功触感，减少动态效果时不触发这些反馈。
- 每个楼层有 VoiceOver 标签和状态；同等操作可用按钮完成，不强制手势。方向按钮命中区域44pt，说明与控件随文字内容布局；最终大字体、VoiceOver与实际触感需要iPhone验证。

## 源码

- `ios/StairClimb/Views/ProgressViewScreen.swift`：交互视图、可取消异步播放、浏览和回放。
- `ios/StairClimb/Core/StepRules.swift`：纯显示规则 `StaircaseRules`，只派生楼层范围与有限播放路径。
- `ios/StairClimbTests/StepRulesTests.swift`：新增7项XCTest，覆盖逐层更新、超大补算上限、跨日/首次/下降、减少动态效果、回放、浏览边界和真实步数不可变。

1. HealthKit成功快照跨过一个楼层，人物登到对应位置；同楼层内更新只改变进度条，重复刷新不能虚增步数。
