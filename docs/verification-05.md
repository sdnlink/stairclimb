# ios_network：真实联网、共享与隐私操作

本轮实现下一待办模块 `ios_network`，没有重写已获业务复核的 `ios_local`。保存的独立复核正文接受本地模块和三个后端模块；其依赖状态/结论记录提示与正文不一致，且没有开放的AUD实现问题，应由reviewer修复记录，不据此改动已经验证的实现。本轮为真实下一模块新增文件，不是为了结论格式制造实现修复。

## 实现边界

- `Network/APIClient.swift`：实际URLSession请求，JSON编码累计汇总，Authorization仅在请求头；12秒请求/20秒资源超时，禁用Cookie/缓存，拒绝重定向，不向另一个服务转发凭证。解码服务器规则和上海日区间，拒绝不兼容数据，错误提示不显示服务端内部详情。
- `Network/ServiceAddress.swift`：可在App注册表单配置根地址，Release仅HTTPS；HTTP仅在Debug允许回环、私有IPv4/IPv6或`.local`本地开发地址。拒绝URL中的账号、密码、路径、查询、片段；与已验证的独立Debug/Release ATS配置配合，不新增通用例外。
- `Network/NetworkVault.swift`：真实服务器身份、随机凭证、绑定地址、上传许可和待完成隐私意图全部存Keychain，与本机UUID分别保存。不将本机UUID当作服务器认证依据。注册失败不假造凭证；服务器已返回凭证而Keychain暂时不可写时，保留内存中该凭证供重试保存，不重复注册。
- `Network/SocialModel.swift`：注册默认私有；刷新/重启不发开启共享请求。用户主动确认后，按最新版本开启共享。同步先取共享版本，再读取HealthKit；仅本次成功可读的当日汇总可上传，读取失败、无可读数据临时0值及昨日结果均不上传。真实读取的0步允许上传。重复操作受串行状态保护，重试重新读取，不重放旧快照。
- 撤回/删除在等待网络前停传并保存意图、使旧响应失效，再等在途请求结束。关闭共享建立服务端版本屏障；删除保存首次尝试的版本，不盲目采用新版本重放。超时/503/401不显示删除完成；版本冲突必须再次由用户确认删除现存数据。非敏感的UserDefaults停传保险标志在Keychain失败后也阻止重启自动上传，只有主动共享成功才清除；凭证不进入UserDefaults。
- `Views/SocialView.swift`：实际注册、改名、公开提示、读取并同步、刷新、遍历下一页、定位本人、撤回及两类删除入口；离线同日结果标明缓存/上海时间，跨日清空，分页版本变化清空旧页。删除未确认时持续显示待完成。只移除本机凭证有明确的远端数据及不可找回警告，隐私操作待完成时禁止丢弃凭证。
- `AppShell`接入原生TabView；首次/回前台刷新资料，已有主动许可才尝试读取同步。前台上海午夜通过本地日区变化清理网络旧值，并等待在途操作后刷新/重读；不把昨日总数换个日期重发。服务器仍每次请求派生日期，无准点后台任务依赖。

原 `LocalAppModel`、HealthKit实现及28个既有Swift测试未改。仅为联网整合调整应用入口、工程源文件关联，以及本机页面的“未共享”静态文案，避免实际共享后产生误导。原始后端、追加需求及历史验证记录保留。圈子仍需独立主动同意，本轮不强制加入，不调用参与开启接口，也不宣称已有圈子页面。
